# 章節

這裡放**正文**，是這本書的唯一真相：定稿照它更新細綱，全書上下文從這裡取正文，工程頁的字數也報它。

一章一個檔案，檔名的數字字首就是章號（細綱號 = 章號）。細綱在 `.novelwarden/summaries/` 下與正文相對路徑相同的位置（`003-夜访.md` ↔ `summaries/003-夜访.md`，分子目錄時細綱也在同名子目錄裡，副檔名一律 `.md`）。
寫正文時模型產出的那一章直接落在這裡；已經有內容時先讓你對比再覆蓋。可以分子目錄收納，章號仍然全書連續；在工具裡改名、移動章節時細綱跟著搬。

老工程直接把已有的章放進來就行：沒有細綱不影響，`chapters/` 裡有檔案就算寫過那一章，可以直接定稿、直接進上下文。

創作流水線見 [../README.md](../README.md)。
