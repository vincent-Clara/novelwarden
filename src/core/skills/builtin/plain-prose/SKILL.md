下面每條都附了例句。拿不準的時候，照改後那句的寫法寫。

【修飾】
1. 名詞前最多留一個修飾語，留讀者不知道的那個。「帶刺的鞭」可以；「沉重的鞭」把「沉重」刪掉。
2. 人物出場後就叫名字或「他」，別用「那肥碩的身軀」代指錢執事。
3. 動詞前別加程度副詞。「狠狠碾壓」改成「碾」，「死死盯著」改成「盯著」。毫不、極其、格外、愈發、徹底、瘋狂、狠狠、死死、深深這幾個詞，一章加起來別超過 5 次。
4. 別用「帶著一股」「透著」「瀰漫著」掛氣味和情緒。氣味要緊，就單寫一句「他身上一股靈草味」。
5. 一個逗號分句裡最多一個「的」。
6. 字數不夠就多寫動作和對白，別靠形容詞湊。

【情緒】
7. 別直接寫「他很憤怒」「她意識到自己被騙了」，寫他做了什麼：他把茶杯放下，沒接話。

【句式】
8. 「不是……而是……」只在糾正誤會時用。「偷賬本的是他弟弟，不是他」可以；「這不是比試，而是生死之戰」改成「這是生死之戰」。
9. 一個意思別拆成幾句重複說。「他笑了。笑得很冷。冷得刺骨。」改成「他冷笑了一聲」。
10. 旁白別發感慨。「有些東西，一旦失去就再也回不來了」這種話，人物在對白裡說可以，旁白別說。

【場面】
11. 別一句話寫完經過。「他找到證據，揭穿了對方」要寫出他看到了什麼、當眾怎麼說的、對方怎麼回的。
12. 兩個人都知道的事，別讓他們在對白裡互相講一遍。
13. 主角贏了也要付點東西，比如受了傷、欠了人情。下一場他還記著這件事。
14. 環境只寫跟人物有關的。下雨就寫雨聲蓋住了腳步，別寫雨夜多麼淒涼。
15. 別寫「所有人都震驚了」，寫一個具體的人怎麼反應：賬房先生手裡的算盤停了。
16. 章末停在一件具體的事上，別寫「真正的危機才剛剛開始」。

【改前 → 改後】
- 錢執事那肥碩的身軀帶著一股濃重的靈草香氣壓了過來。他一臉橫肉，眼神中透著毫不掩飾的貪婪與厭惡。
  → 錢執事走了過來，一身靈草味，滿臉橫肉。
- 他抬起腳，毫不客氣地踩在陸沉的手背上，狠狠碾壓。
  → 他抬腳踩住陸沉的手背，碾了兩下。
- 林舟很快意識到有人在陷害他，於是決定反擊。他冷靜地找到證據，成功揭穿了對方。
  → 林舟把採購單翻過來看了看，日期是三天前的，墨還沒幹。他把單子推到桌子中間：「誰籤的？」

【另外】
- 傷勢、數值、來歷、第一次出場的樣子，情節用得上就照寫。
- 對白按角色設定寫，上面修飾和句式那幾條不管對白。
- 別把句子全改短。
- 細綱裡沒有的事件別加。上面說的經過和代價，都從細綱已有的事裡寫。
