# 繁體中文（臺灣）本地化

本分支的介面、通知與錯誤訊息、說明文件、中文註解、內建提示詞、寫作技能、範例小說及相關測試均採繁體中文。以 OpenCC `s2twp`／`s2tw` 起稿，再人工檢查語境與臺灣術語；內建提示詞的中文輸出要求改為繁體中文。

## 相容性界線

- **不變更既有資料格式**：識別字、API／協定欄位、命令名稱、JSON 鍵與儲存列舉保留原值。例如 `语言习惯`、`当前状态`、`主线`、`推进`、`calendar: 简单历`，仍是程式使用的鍵或資料值，不是漏譯。
- **不變更既有檔案路徑**：包含 `导出/`、`threads/时间线.md`、`threads/未归属的伏笔.md`，以及範例小說原有的中文檔名。標題與顯示名稱可以是繁體，路徑不能隨翻譯改名。
- 固定小節標題、敘事線種類／事件、日期與數字解析接受繁簡別名；儲存資料仍使用原有鍵。`src/core/model/labels.ts` 只負責受控標籤與別名，不是任意文章的即時翻譯器。
- **不在執行期間轉換作者原文**：作者的正文、名稱、路徑、自訂內容及引用原文均保持輸入時的字樣。這次僅將版本庫內附的範例文字轉為繁體，並同步更新範例的內容指紋。
- 連結、外部產品／模型名稱、相依套件與鎖定檔保持原樣；相容性測試及解析器中的簡體字是刻意保留。文件中有被引用的舊小節連結，也保留原有錨點。

## 圖片與驗證限制

`docs/screenshots/` 內既有的五張 PNG 截圖仍可能含簡體中文字；這次沒有瀏覽器可供重新擷取，因此沒有修改圖片或宣稱完成畫面目視驗證。二進位檔、相依套件、鎖定檔及產生的建置檔案均不納入文字轉換。

驗證使用專案現有的 `npm test`（TypeScript 型別檢查、Node 測試、Bun 端對端測試）與 `npm run compile`。另新增 `tests/contract/localization.test.js`，檢查繁簡小節、佔位文字、列舉、日期、保留檔名與提示詞語言，避免日後把顯示翻譯誤用於資料鍵或作者原文。
