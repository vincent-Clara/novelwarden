# 規劃時的前情分三段：大綱與拆細綱不再隨章數漲

> 2026-10-22。單獨一件，**在 main 上直接開發**。接著 [2026-10-21-outline-per-chapter.md](2026-10-21-outline-per-chapter.md)（按遠近帶）與 [2026-10-22-outline-from-plots.md](2026-10-22-outline-from-plots.md)（大綱是各章梗概的彙總）。起因：盤點上下文時實測（128k 視窗、第 3 級）——寫正文與章數無關（約 2 萬 token），續寫大綱、拆細綱卻隨章數線性漲：「更早的只帶第一行」每章約 140 token、強制帶、不受詳細度管，第 300 章時續寫大綱 4.8 萬、拆細綱 6.3 萬，七八百章撐爆視窗；拆細綱時大綱與前序細綱一覽把同一批細綱各帶一遍。

## 作者定的（2026-10-22）

| # | 問題 | 定案 |
|---|---|---|
| 1 | 全文大綱落後（只有批次寫章、補齊、手動重建才更新）時遠段怎麼辦 | **照樣封頂**，明細裡寫「全文大綱只寫到第 k 章：第 k+1–c 章這次沒帶」；不自動調模型 |
| 2 | 中段上限 | **沿用 `plotListMax`**（30 / 50 / 100 / 不限），不另設一項、不改數 |
| 3 | 拆細綱去重之後區間前 10 章的梗概 | **不帶**：已經拆過的章由前序細綱一覽（關鍵事件）與前幾章細綱帶 |
| 4 | 真實模型試跑 | **跑**：假的 300 章長工程，續寫大綱、拆細綱各一次 |

## 三段（大綱階段：續寫 / 重寫 / 討論大綱）

| 段 | 哪幾章 | 怎麼帶 |
|---|---|---|
| 近段 | 區間前 10 章到區間末（沒給區間：最後 10 條） | 整條，P0 force（不變） |
| 中段 | 近段再往前，最多 `plotListMax` 章 | 一章一行（梗概第一行，≤100 字），**不強制**：放不下從最老的丟起 |
| 遠段 | 更早的 | 不逐章列，交給全文大綱 |
| 區間之後已排好的 | 重寫時 | 一章一行，**不強制**：放不下從最遠的丟起（不封條數） |

- 填預算的先後：近段（強制）→ 中段（由近及遠）→ 區間之後（由近及遠）。還是一個條目 `outlineDoc`，截過的標 degraded。
- 全文大綱在大綱、細綱兩張配方里 **P2 → P1**：它要接住遠段。
- 明細（第 2 條）：哪幾章整條、哪幾章一行；遠段「第 1–c 章沒逐章列（只列最近 N 章，上下文詳細度「X」），前情看全文大綱」；全文大綱沒有或沒寫到 c 章時照實說；預算截掉的寫明哪幾章。

## 拆細綱：同一批細綱不帶兩遍

- `outlineDoc` 只帶**這一次要拆的**：批次是區間裡那幾條（空殼上的梗概就是這一次的上游），外加**區間前面還沒拆的空殼**（沒有關鍵事件，前序細綱一覽不列它們）；單章時這一章的梗概已經在本章細綱裡，只剩前面的空殼，一條都沒有就不出這一層。區間之後的照舊不帶。
- 已經拆過的章：前幾章細綱（單章，`plotPrev`）+ 前序細綱一覽（`plotList`，最多 `plotListMax` 章）。一覽也改成**放不下從最老的丟起**（從前整份丟），封頂時同樣寫明更早的看全文大綱、全文大綱寫到哪。
- 更早的：全文大綱（P1）。

## 預計（估算，第 3 級、128k 視窗）

| 呼叫 | 第 100 章 | 第 300 章 |
|---|---|---|
| 續寫大綱 20 章 | 2.1 萬 → 約 2 萬 | 4.8 萬 → 約 2.2 萬 |
| 拆細綱 5 章 | 3.7 萬 → 約 2.1 萬 | 6.3 萬 → 約 2.1 萬 |
| 寫正文 | 不變 | 不變 |

第 4 級仍然不封條數，但中段與一覽都按預算截，不會再因強制層超長被服務商拒。

## 不做

- 按卷摺疊（沒有卷簡介可用）；更準的 token 計數；寫正文那張配方；全文大綱自動更新。
- 「區間之後已排好的」不封條數：它只在重寫中段時出現，量取決於排到了多遠，不隨寫到第幾章漲。
