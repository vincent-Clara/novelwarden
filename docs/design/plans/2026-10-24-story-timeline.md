## 現狀

細綱有「時間地點」一節（`plotFile.ts:104`），拆細綱時模型寫「本章的時間點（與上一章的相對關係亦可）」（`context/prompts.ts:1228`），
定稿照正文改寫時同樣寫一句（`summarizePrompt.ts:17`）。寫出來的都是「第 2 章當夜三更」「次日清晨」這樣的相對說法，**沒有人把它們

## 總覽

```
同步第 N 章 ── 認事件那一次（+0 次）順帶報：本章比上一章晚幾天、跨了幾天、時段、原文依據
                 │
                 ▼
 threads/时间线.md：一章一行「第 N 章：+2 天，清晨〔依據：「兩日後的清晨」〕」（機器只寫相對的「+N 天」）
                 │  作者把哪一行改成具體日期（「八月十五」「第 200 天」），哪一行就是錨點，後面的跟著順延
                 ▼
 model/timelineFile.ts 現算（不落盤）：每章開頭是第幾天 → 按曆法換成日期
                 │
   ┌─────────────┼────────────────────┬──────────────────────────┐
   ▼             ▼                    ▼                          ▼
工程頁敘事線頁籤   敘事線總覽              寫正文 / 拆細綱的上下文         從正文補推（已判過敘事線、
「時間線」一行     「故事時間」一行與月份帶   「上一章結束於三月十四傍晚」    還沒有時間的章；幾章 1 次）
```

- **機器只寫相對量，日期一律現算**：檔案裡機器寫的是「比上一章晚幾天」，日期在顯示時從第 1 章往後累加出來。這樣作者定死第 12 章是
  八月十五，第 13 章往後機器推的日期**自動跟著挪**，不用機器回頭改一序列。
- **狀態不落盤**（第 18 條）：每章是第幾天、推不出的有幾章、還沒推的有幾章，都從這份檔案與章節現算。

## 資料格式：`.novelforge/threads/时间线.md`

```markdown
---
calendar: 簡單歷
start: 大衍三年三月初七
generatedBy: novelwarden
---

# 時間線

> 一章一行，寫的是這一章開頭比上一章結尾晚多久。日期在敘事線頁籤和總覽裡看（按 start 往後推算）。
> 要定死哪一章，把「+N 天」改成具體日期（如「八月十五」）或「第 N 天」；你改過的行機器不再動，後面的章跟著順延。

- 第 1 章：+0 天，傍晚〔依據：「連日大雨的第三天傍晚」〕
- 第 2 章：+0 天，夜裡〔依據：「當晚」所在的那一句〕
- 第 4 章：+1 天，清晨，歷時 2 天〔依據：「次日清晨，雨停了」〕
- 第 7 章：回憶，約二十年前〔依據：「那是二十年前的冬天」〕
- 第 9 章：+?〔推不出：正文沒交代過了多久〕
- 第 10 章：+0 天，上午〔推測：緊接上一章的審訊〕
- 第 12 章：八月十五，傍晚
- 第 13 章：+3 個月
```

### frontmatter

| 鍵 | 值 | 缺席 |
|---|---|---|
| `calendar` | `简单历` / `公历` | 簡單歷 |
| `start` | 第 1 天是哪天：`大衍三年三月初七`、`三月初七`、`2026-03-07`、`2026年3月7日` | 只顯示「第幾天」 |

- frontmatter 的鍵只認英文（`model/markdown.ts`），值可以是中文。行內不寫 `#` 註釋（解析器不剝），說明放在正文開頭的引用塊裡，解析時忽略。
- **簡單歷**：每月 30 天、一年 12 個月。起點認「[年號][N 年]M 月[D 日]」：年號、年、日都可以缺（缺日當初一）；數字認阿拉伯數字與
  漢字（「十四」「廿一」「初七」「正月」「臘月」「冬月」）。輸出照起點的寫法：起點寫「三月初七」就出「三月十四」「次年三月十四」，
  寫「3月7日」就出「3月14日」，有年號就帶年號、年份往上加。
- **公曆**：真實的月份長短與閏年。起點認 `2026-03-07`、`2026年3月7日`、`2026/3/7`；輸出照起點的寫法。
- 起點認不出：照「沒填」處理（只顯示第幾天），工程頁那一行說一句「起點認不出」。

### 一行的寫法

`第 N 章：值[，時段][，歷時 M 天][〔依據：「原文」〕 | 〔推測：理由〕 | 〔推不出：理由〕]`，專案符號與線的「進展」同一套認法。

| 值 | 意思 | 誰寫 |
|---|---|---|
| `+N 天`（`-N 天`、`+N 周`、`+N 個月`、`+N 年`、`+半個月`；漢字數字也認） | 本章開頭比上一章結尾晚多久。月按 30 天，年按曆法（簡單歷 360 天、公曆 365 天） | 機器寫天，作者也可以寫 |
| `同日` / `當天` / `次日` / `第二天` / `翌日` | 等於 `+0 天` / `+1 天` | 作者 |
| `+?` | 推不出：按「緊接上一章」（`+0 天`）算，介面上標出來等作者補 | 機器 |
| `回憶[，約二十年前]` | 整章是回憶或倒敘：不推進時間，下一章接著上一章算 | 機器、作者 |
| 一個日期（`八月十五`、`大衍四年正月初一`、`2026-08-15`） | **錨點**：這一章開頭就是這一天。沒寫年份的，取上一章結尾當天或之後最近的那一個 | 作者 |
| `第 N 天` | 錨點：這一章開頭是故事第 N 天 | 作者 |

- **時段**只認一個短詞（凌晨 / 清晨 / 早上 / 上午 / 中午 / 午後 / 下午 / 傍晚 / 黃昏 / 夜裡 / 晚上 / 深夜 / 半夜 及「三更」這類），
  只顯示。**歷時**缺席是 1 天（同一天裡寫完）。
- **認不出的行**（值認不出、日期在沒填起點時寫了月日）：原樣留著、不當這一章的時間（第 1 條），演算法上按「這一章沒推」處理，工程頁說
  「幾行認不出」。

### 推算（現算，`computeTimeline`）

從第 1 章往後走到檔案裡出現過的最大章號：

```
上一章結尾 E（第 1 章之前當 0）
第 N 章：
  沒有這一行      → 開頭 = E（按緊接上一章算），標「沒推」
  回憶            → 不改 E，這一章標「回憶」
  錨點（日期/第幾天）→ 開頭 = 那一天
  第 1 章的相對值  → 開頭 = 第 1 天（差值不算：第 1 章就是起點）
  +N              → 開頭 = E + N
  +?              → 開頭 = E，標「推不出」
  結尾 = 開頭 + 歷時 − 1；E = 結尾
```

一章的狀態：有依據（實心）/ 推測（淡）/ 推不出（黃）/ 沒推（灰虛）/ 錨點（作者定的）/ 回憶 / 認不出。「故事裡過了幾天」= 最後一章的結尾。

## 誰能寫什麼

| 內容 | 誰寫 | 怎麼寫 |
|---|---|---|
| 這份檔案 | 同步、補推 | 第一次要寫時按模板新建（只追加：新檔案） |
| 第 N 章那一行 | 同步第 N 章、補推 | **只填空**：沒有這一行就按章號插到對的位置 |
| | | ⚑ 已有這一行時**只在兩種情況下換**：值還是 `+?`、標著〔推不出〕（作者沒動過）；或者〔依據〕裡那句原文已經不在正文裡了（正文改過，舊版先存歷史，同敘事線「證據不在正文裡的機器事件」） |
| | | 其餘一律不動：作者寫的錨點、作者改過的值、〔推測〕的行、〔依據〕還在正文裡的行 |
| frontmatter、引用塊、作者寫的任何行 | 作者 | 機器一個字不動 |

- ⚑ **沒有指紋**：一行一章、幾百上千章，逐行記指紋太重；改用上面「只填空」的規矩——機器從不改寫一行已有、還站得住的記錄。要機器重推
  哪一章，刪掉那一行再同步（或補推）。代價：正文改了、〔依據〕那句還在、時間卻變了的，舊記錄留著（保守，寧可不改）。
- ⚑ **日期不寫進檔案**：檔案裡只有相對量與錨點，日期在敘事線頁籤、總覽、上下文裡現算。寫進去的話，作者改一個錨點，後面幾百行的日期
  就全是舊的，機器還得分清「哪一個是作者改的、哪一個是沒重新整理的」。檔案開頭的引用塊說清這一點。

## 一、同步時推（認事件那一次，+0 次）

- **輸入**多一段「【上一章的時間】」：`第 11 章：三月十四 傍晚（故事第 8 天，歷時 1 天）〔依據：「…」〕`；上一章沒有記錄寫「上一章的
  時間還沒記，按正文判這一章比上一章晚幾天」；第 1 章寫「這是第 1 章，days 寫 0」。按「寫到第 N 章時」算（只看第 N 章之前的行）。
- **輸出**多一個欄位（`THREAD_FIND_SYSTEM`）：

  ```json
  "time": { "days": 1, "span": 1, "part": "清晨", "flashback": "", "evidence": "次日清晨，雨停了", "reason": "" }
  ```

  - `days`：本章開頭比上一章結尾晚幾天，同一天 0、第二天 1，往回跳寫負數；正文沒交代、也看不出寫 `null`；
  - `span`：本章從頭到尾跨了幾天（同一天裡是 1）；
  - `part`：本章開頭的時段，看不出不寫；
  - `flashback`：整章是回憶或倒敘時寫大約多久以前（「約二十年前」），否則空；
  - `evidence`：正文裡交代時間的那一句，逐字；沒有這樣一句（靠場面接續判的）就空著、在 `reason` 裡寫為什麼這麼判（≤30 字）。
- **校驗**（`verifyTime`）：`days` 是整數、絕對值不超過 3650 萬天（約十萬年，修仙夠用）；`span` 是 1 起的整數（同上限），缺了當 1；
  證據照事件的口徑逐字校驗，找不到就在正文裡找最接近的一句（`nearestSentence`），還找不到就丟掉證據、改記〔推測：依據在正文裡找不到〕。
  `days` 是 `null` → `+?`〔推不出：reason 或「正文沒交代過了多久」〕；有 `flashback` → `回憶，…`。模型根本沒給 `time`：**不寫這一行**、
  記一筆日誌（之後補推能補上）。
- **寫盤**：在認事件落盤之後、當前進度之前（與推水位同一處），按上表「只填空」寫這一行。寫不進去只記日誌、不算認事件失敗。
- **完成提示**跟在敘事線那一句後面：「時間：第 12 章 +2 天（依據「兩日後」）」、「時間推不出（按緊接上一章算，可以在時間線裡補）」、
  「時間：第 12 章的時間你定過，沒改」。
- 從已寫正文補記（`threadsBackfill.ts`）走的是同一個 `recordThreads`，補記的章順帶也有時間。

## 二、從正文補推（敘事線判過、還沒有時間的章）

本稿之前就判過敘事線的章（水位以內的、`threadsJudged` 裡的）不會再走認事件，它們的時間要另補。

- **入口**：工程頁「敘事線」頁籤「時間線」那一行有「⚠ 第 3–30 章還沒推」時，標題旁給「補推時間」（右鍵標題、那一行也有）；補推在跑時不給。
- **範圍**：⚑ 定稿過、正文沒再改過、**敘事線判過**、時間線裡還沒有這一行的章。敘事線還沒判的章不歸它管——「從正文補記」會一起推時間，
  省得同一章花兩次錢；它們在那一行裡說「敘事線補記時會一起推」。
- **一次幾章**：⚑ 按章號序列，一次最多 5 章，放不下就少放（每章正文放不下截尾，證據仍對整章校驗）。輸入是這幾章的正文與「這一批之前
  那一章的時間」，輸出 `{"times":[{"chapter":12, …同上}]}`。後一批要看前一批的結果（上一章的時間），所以序列。
- **次數**：⌈章數 / 5⌉ 次左右（按字數切批，確認框寫明上限），「定稿」檔（`plotSummary`），經 `askCall`，先存一個存檔點。
- **失敗**：一批沒成就停（同補記 ⚑10），已寫的留著，失敗掛在時間線檔案上（紅 ❗），再點一次從那一章接著補。
- ⚑ **不給外部 agent**：這是一次性的補課，補記（`extract threadsFromText`）已經順帶推時間。以後要再加。

## 三、用在哪

### 工程頁「敘事線」頁籤：一行「時間線」

`🕒 時間線 · 推到第 30 章 · 現在：三月十四 傍晚 · 故事裡過了 46 天`，有問題的另加 `⚠ 2 章推不出`、`⚠ 第 3–30 章還沒推`、`⚠ 1 行認不出`、
`⚠ 起點認不出`。沒填起點時「現在：第 46 天」。

- 懸停：曆法與起點、推不出的是哪幾章、錨點在哪幾章。點一行開啟 `时间线.md`；右鍵：開啟、在總覽裡看、補推時間（要補時）。

- 文案後端給（`views/threads.ts`，同別的行），前端只加 ⚠。

### 敘事線總覽

- **表頭多一條月份帶**（有起點時）：同卷名那一行的畫法，連著幾章在同一個月就併成一段「大衍三年三月」；跨年、跨月處斷開。
- **線的上面多一行「故事時間」**：每章一格，寫這一章開頭是幾號（簡單歷「十四」、公曆「14」、沒起點「46」）；和上一章同一天的畫一個點，
  推不出的標黃「?」，沒推的灰、回憶的寫「憶」。懸停看全文：`第 12 章 · 三月十四 清晨 · 故事第 8 天 · 上一章後 +2 天 · 歷時 3 天`，
  依據 / 推測 / 推不出的理由。**點格子開啟 `时间线.md`**（這一行是拿來改時間的；點章號照舊開啟那一章）。
- 線與伏筆格子的懸停，標題後面帶上那一章的日期；伏筆名的懸停多一句「埋下至今 46 天」（還沒收的，按敘事線判到的那一章算）。

### 寫正文、拆細綱的上下文

- `threads` 層（P1）多一個條目「故事時間」（id `timeline:<路徑>`），**單獨成一節**放在敘事線那一節前面：
  - 寫第 N 章：`上一章（第 11 章）結束於大衍三年三月十四傍晚（故事第 8 天）。本章的時間要接得上；細綱「時間地點」寫了的照它。`
  - 拆第 a–b 章：`已寫到第 11 章，結束於大衍三年三月十四傍晚（故事第 8 天）。細綱「時間地點」寫清本章比上一章晚多久。`
- 按「寫到第 N 章時」算（只看第 N 章之前的行）：重寫前面的章不帶後面的時間。沒有時間線、或第 N 章之前一行都沒有：不出。
- 一行幾十個字，不佔敘事線的條數與字數（不和線搶名額），明細裡照常列出、可以取消勾選。審稿、續寫、修稿不帶。

## ⚑ 彙總（本稿自定的）

1. 機器只填空、不改已有的行（`+?` 和證據已經不在正文裡的除外），不記逐行指紋；要重推哪一章，刪掉那一行。
2. 檔案裡不寫日期，日期一律現算：改一個錨點，後面的章自動順延。
3. 推不出（`+?`）與沒推的章都按「緊接上一章」（+0 天）算，介面上標出來。
4. 第 1 章的相對值不算：第 1 章開頭就是第 1 天。
5. 整章回憶不推進時間；一章裡的插敘不管。
6. 補推只管敘事線判過的章；還沒判的交給「從正文補記」一起推。
7. 補推一次最多 5 章、序列，按字數切批；一批沒成就停。不給外部 agent。
8. 上下文裡的「故事時間」單獨成一節、不佔敘事線的條數與字數。
9. 總覽上點「故事時間」那一格開啟時間線檔案（拿來改），不是開啟那一章。
10. 年份沒寫的錨點取上一章結尾當天或之後最近的那一天；`days` 上限十萬年。
