## 借鑑了 andrea-novel-helper 什麼

它的時間線是作者手寫的 `.tjson5`（事件、連線、自由畫布 + 一條只能看的橫軸 + 按分組的甘特），日期只認公曆，不從正文抽。我們的時間是
同步時從正文推出來的、一章一行，所以只借三樣：**時間軸按日子排、對不上的直接標紅**、**卡片上帶它關聯的東西**（它是角色與章節，我們是
這一章在各條線上發生了什麼）、**回憶用虛線**。

## 一、編輯區「時間線總覽」（新的特殊標籤）

和「敘事線總覽」並排的另一個不對應檔案的標籤（`editor/store.ts` 的 `SpecialTab`），只在獨立版、桌面版有（外掛形態沒有內建編輯器，
同敘事線總覽，能力探測）。資料按需要：顯示出來時發 `requestTimelineOverview`，後端回 `timelineOverview`（純讀盤、不調模型、不落盤）；
顯示著收到 `state` 停一下再要一次。

```
時間線總覽  簡單歷 · 起點 大衍三年三月初七 · 推到第 30 章 · 故事第 46 天    [只看有問題的] [全部線 ▾]   [重新整理]
⚠ 第 4 章：前面推下來是三月初八，正文寫三月十五（差 7 天），已按正文對齊
──────────────────────────────────────────────────────────────
大衍三年三月 · 春
  初七   ●─ ┌ ● 第 1 章 楔子                         傍晚 → 深夜 ┐
  第1天  │  │ 依據「連日大雨的第三天傍晚」                          │
         │  │ [名冊之謎] 林昭拿到名冊  [未歸屬] 埋〈玉佩的來歷〉     │
         │  └────────────────────────────────────────────────────┘
         │  ┌ ● 第 2 章 客棧裡的女人                  同一天 夜裡 ┐ …
         ┆  5 天后
  十三   ●─ ┌ ◆ 第 4 章 空匣             清晨 → 十五 夜裡 · 3 天 ┐
         │  │ 正文寫明三月十五「今夜便是十五」                       │
         │  │ ⚠ 前面推下來是三月初八，正文寫三月十五，已按正文對齊   │
         │  └──────────────────────────────────────────────────┘
         │      ┌╌ ↺ 第 6 章 同路（回憶，約二十年前） ╌┐
大衍三年四月 · 夏
  初一   ●─ ┌ ★ 第 8 章 鐵匠鋪（你定的） …
```

- **軸**：一個故事日子一行（同一天的幾章疊在一起，按章號），左邊寫那一天（有起點寫 `初七`，下面小字 `第 1 天`；沒起點只寫 `第 8 天`）。
  ⚑1 **按故事日子排**，不按章號：往回跳的章排到它那一天去（對賬照舊報它）——時間線要看的就是故事裡誰先誰後。
- ⚑2 **只壓空白、不按比例**：中間沒有章的日子壓成一行「N 天后」（差 2 天以上才有這一行；次日不畫，日子變了一眼看得出）。
- **月份分隔**（填了起點）：月份變了插一行 `大衍三年三月 · 春`（季節按曆法現算，同對賬的口徑），年份沒變的只寫月。沒起點不分隔。
- **卡片**（一章一張）：狀態點、`第 N 章 標題`、右邊那一天的時段（`清晨 → 夜裡`，跨天的 `→ 十五 夜裡 · 3 天`）；下面依據 / 推測 / 正文寫明 /
  你定的；然後是**這一章發生了什麼**：
  - 敘事線的**實際**事件（計劃的不畫），一條一個：線名做成彩色小標籤 + 事件；伏筆的寫 `埋〈玉佩的來歷〉`。⚑3 最多 3 條，其餘「還有 N 條」，
    點開看全。⚑4 線的顏色按敘事線的排序前 8 條各一色、**不迴圈**（實施時改的：迴圈會讓兩條線撞色），第 9 條起與「未歸屬的伏筆」一樣灰；
    名字總寫在標籤上，顏色只是幫著認。8 色是一套校驗過色盲區分度的分類色，深色一套、淺色與護眼一套。
  - 這一章一條事件都沒有：細綱的梗概（淡色）。
  - 對賬報了這一章：紅字一條一行，卡片左邊一道紅邊。
- **回憶章**（⚑5）：掛在閱讀順序上前一章那一天裡，跟在那一章後面，縮排、虛線框、↺；寫「回憶（約二十年前）」。它的日子推不出來，不上軸。
- **還沒推、推不出、認不出的章**：照推算的位置（按緊接上一章算）放上去，狀態點照工程頁（`·` `?` `✕`），卡片淡一些。時間線寫到的最後一章
  之後、同步過還沒推的章不上軸，最上面一條 ⚠ 說「第 31–35 章還沒推」（⚑6）。

### 互動

- **單擊一張卡片：展開 / 收起詳情**（同時標成選中）。詳情：開頭 → 結尾的全稱、故事第幾天、比上一章、歷時；依據原文 / 推測理由；正文寫明的
  日子與原文、照它對齊了幾天；季節與原文；對賬的幾條；這一章在各條線上的全部事件（帶原文證據）；細綱的「時間地點」。
- **右鍵一張卡片**：改時間…、重推這一章、從這一章起重推、開啟正文、開啟細綱、開啟時間線檔案。改時間、重推都是工程頁同一個動作
  （`projectAction`），後端照舊先問。
- **右鍵標題欄與空白處**：改曆法與起點…、填為起點（有建議時）、補推時間（有還沒推的）、重推機器寫的 N 行、開啟時間線檔案、重新整理。
  ⚑7 標題欄上只放「重新整理」與兩個篩選，設定與補推、重推都在右鍵（作者那條：設定放右鍵）。
- **篩選**（只在前端，不記住）：「只看有問題的」只留對賬報了的章與推不出、認不出的章；「線」下拉只留在那條線上有實際事件的章。
  篩掉之後空出來的日子不畫，「N 天后」照留下的那幾天重算。
- **從工程頁過來**：帶章號就展開那一張、滾過去（見「二」）。

## 二、工程頁「時間線」組

- **去掉第一行「曆法與起點」**。曆法與起點挪到組標題的懸停裡；「改曆法與起點…」只在右鍵（組標題、組裡空白、每一行都有）。
  - 沒填起點、正文寫明過日子：對賬那幾條裡多一條 `⚠ 沒填起點：第 3 章寫了「三月初七」，第 1 章是三月初五`，右鍵「填為起點」。
  - 起點認不出：一條 `⚠ 起點「很久以前」認不出，先只顯示第幾天`，右鍵改。
- **點一章：開啟時間線總覽，展開這一章**（不再開啟正文，推翻上一稿 ⚑10）。開啟正文挪到右鍵「開啟這一章」。
  - ⚑8 外掛形態沒有內建編輯器：點一章開啟時間線檔案（時間線的原文，至少是看時間，不是看正文）。
- **點一條 ⚠**：帶章號的開啟總覽、展開那一章；不帶的（「第 31–35 章還沒推」）開啟總覽。外掛形態照舊開啟時間線檔案。
- 標題旁的「總覽」開啟時間線總覽（原來開啟敘事線總覽、滾到時間線那一組）。「補推時間」「重推」照舊。

## 三、敘事線總覽

- 去掉「時間線」一組（「故事時間」那一行）與表頭的月份帶：它只管線與伏筆。
- 列頭與格子的懸停裡照舊帶一句「這一章是哪天」（`三月十四 清晨`），伏筆名的懸停照舊帶「埋下 N 天」。
- 敘事線組標題旁的「總覽」只看有沒有線、有沒有未歸屬的伏筆，不再看時間線。
